# Sayı Tahmin Oyunu

C# kullanılarak geliştirilen basit bir sayı tahmin oyunudur.

## Projenin Amacı

Bilgisayarın 1 ile 100 arasında rastgele tuttuğu sayıyı kullanıcının tahmin etmesini sağlar.

## Özellikler

- 1-100 arasında rastgele sayı üretme
- Kullanıcıdan tahmin alma
- Daha büyük / daha küçük şeklinde ipucu verme
- Deneme sayısını gösterme
- Doğru tahminde oyunu sonlandırma
- Tekrar oynama seçeneği

## Kullanılan Teknolojiler

- C#
- .NET Console Application
